AuraTutor – AI-Powered Tutoring System That Adjusts to Student Pace

An AI-powered adaptive learning platform designed to personalize education based on each student's learning speed, performance, and understanding. The project aims to improve learning outcomes by providing customized lessons, quizzes, progress tracking, and AI-assisted doubt resolution.

🎯 Project Objective

Traditional classrooms follow a one-size-fits-all approach where every student is expected to learn at the same pace. AuraTutor introduces an adaptive learning model that continuously analyzes student performance and adjusts lessons, quiz difficulty, and explanations according to individual learning needs.
